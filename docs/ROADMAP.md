## 1. 通用约束（每个任务都适用）

- **技术栈：** Vue 3 + TS + Vite。数据存在本机 IndexedDB（`src/lib/storage.ts`），**不新增运行时依赖**；图表用手写 SVG。
- **验收命令：** 每个任务都要跑 `npm test`、`npm run check`、`npm run build`，三项必须全部通过。新的领域逻辑放 `src/domain/`，在 `tests/` 加 `node --test` 用例。
- **数据兼容：** 新字段一律设为可选。旧 workspace 和旧备份 JSON 要能正常加载，`src/domain/workspace-schema.ts` 的校验同步放宽或扩展，并补“旧数据仍能导入”的测试。
- **三处同步：** 新增照护类型或字段时，下面三处要一起改，缺一处就算未完成：
  1. `src/domain/care-types.ts`（类型、`CARE_LABELS`）
  2. `src/domain/voice-parser.ts`（本机规则）
  3. `src/domain/ai.ts`（AI 输出白名单）
- **UI：** 在 375px 和 320px 宽度下不能横向溢出，触控区至少 44px，字号用 `base.css` 里的变量。
- **医疗相关文案：** 只描述数据，不做诊断，统一附“以医生/接种门诊为准”。

## P0 防丢数据（最先做）

背景：开启防跨站跟踪时，Safari 会删掉 7 天无交互站点的 IndexedDB。主屏幕 Web App 与 Safari 的存储也是隔离的。目前代码没有调用 `navigator.storage.persist()`。

- [x] **P0.1 Web App Manifest + 图标**
  - 在 `public/` 下加 `manifest.webmanifest`，包含 name、short_name、`display: standalone`、theme_color 和 192/512 图标；`index.html` 引入 manifest，并加 `apple-touch-icon`。
  - 不做 Service Worker（离线缓存另议）。
  - 验收：Chrome DevTools 的 Application → Manifest 无报错；iOS 能“添加到主屏幕”，打开后没有地址栏。
- [x] **P0.2 持久化存储申请**
  - 首次保存记录后调用 `navigator.storage.persist()`，结果显示在家庭页（已持久化 / 浏览器未批准 / 不支持）。
  - 验收：桌面 Chrome 显示“已持久化”；函数做成可注入，以便测试不支持的分支。
- [x] **P0.3 迁移引导**
  - 家庭页加一张说明卡：“Safari 和主屏幕数据不互通：先导出备份 → 添加到主屏幕 → 在主屏幕应用里恢复”。
  - 以 `matchMedia('(display-mode: standalone)')` 判断当前环境，Safari 与主屏幕应用显示不同文案。
- [x] **P0.4 备份提醒**
  - 导出成功后，把时间写入 localStorage `babytime.lastBackupAt`。
  - 有记录且超过 7 天未备份时，在今天页顶部显示可关闭的提醒，点击直接导出。
  - 验收：用单元测试覆盖“是否该提醒”的纯函数（无记录、刚备份、8 天前备份）。

## AI 融入设计

### 原则（沿用阶段 8 的约定，不新增例外）

- **默认关闭，按需调用：** 只在用户点按钮时调用。不在后台跑，不自动分析，不定时推送。
- **AI 只出草稿：** 结果要么进现有确认流程，要么只展示、不写入。AI 不直接落库，也不改已确认的记录。
- **只发文字，且发最少的字：** 原片、缩略图、宝宝姓名和生日都不发。月龄只发数字；能发聚合统计的，就不发逐条记录。
- **本机规则兜底：** 每个 AI 入口都要有不依赖 AI 的同等路径。AI 失败时报出明确错误，用户可一键回到本机结果。
- **医疗边界：** 体温、用药、疫苗、生长相关的输出只能描述数据，不给诊断、剂量或接种建议。提示词要写明这条，输出也要在代码里校验（见下文“守门”）。
- **复用现有结构：** 每个能力 = `domain/ai.ts` 里的「提示词构造函数 + 输出解析/白名单函数」+ `lib/ai-service.ts` 的现有调用。不新增服务层，也不引入 SDK。

### 逐项评估

| 功能 | 融入 AI？ | AI 做什么 | 不交给 AI 的部分 |
|---|---|---|---|

### 成本与性能

- 每次调用都由用户点击触发，不做预取。
- 聚合输入 30 天约 1–2 KB，单次 token 很小，不需要缓存。
- 手动触发且结果不保存，所以不做结果缓存。用户反馈重复点击浪费时再加。

## 明确不做

社区、商城、在线问诊、知识库；疫苗预约与库存查询；SweetSpot 式睡眠预测与睡眠训练计划；看图识别里程碑、实时监控；剂量推荐。
