## 2. 设计要点

### 2.1 体检日程（P8.1）

- 静态表 `data/child-health-checks.ts`：节点 id、名称、参考月龄、项目标签（血常规 / 听力 / 视力 / 口腔）。共 13 次：新生儿访视（出院后 1 周内，无固定日期，只作清单项）、满月（28～30 天，按天数不按自然月）、3/6/8/12/18/24/30/36 月龄、4/5/6 岁。
- 参考日期按生日加自然月，复用 `vaccines.ts` 的月末顺延；状态口径与疫苗一致（已完成 / 30 天内 / 已过 / 未到）。血常规 6～8 月龄写成区间，不拆成两个日期；听力挂在 6/12/24/36 月龄节点。
- 早产不做矫正，页面写「早产或有高危因素的宝宝随访更密，按医生安排」。这一条目前只见于转载页，录入前对照规范原文。
- 存储（P8.0 待定）：A 放进宝宝档案 `healthChecks: Record<节点 id, { date; place?; note?; teethCount? }>`，结构同里程碑，`mergeProfiles` 按 key 取并集并带取消标记，不动服务端；B 做新顶层集合，同步服务端要加集合与校验，工作量更大。推荐 A。

### 2.2 BMI（P8.2）

- 不存储，由同一自然日的体重与身高派生：体重 kg ÷ 身高 m²，保留 1 位小数，缺任一项不算。表 A.9/A.10 的年龄列是「岁 月」写法，提取脚本要换算成月龄并校验行数连续。
- `GrowthMetricId` 加 `bmi` 后，`referenceAt` / `referenceLines` / `percentileBand` 直接复用，早产矫正月龄沿用现有逻辑；文案只写区间，不写超重、肥胖。

### 2.3 睡眠参考（P8.3）

- 按完整月龄分档：0～3 / 4～11 / 12～35 / 36～71 月龄，72 月龄起不显示。
- 参考值是 24 小时总睡眠（含白天小睡）。趋势图只对已过完的日子画参考带，不拿今天未过完的数据对比；今日卡片只写参考范围，不并列判断。原文对范围外写「提示需要进一步医学评估」，应用内不照搬。

### 2.4 发育观察（P8.4）

- 44 条存静态表。按原文规则「检查日期介于两个月龄段之间的按最近的小月龄内容」，取不超过当前月龄的最近检查点。
- 勾选存 `warningSigns: Record<检查点:序号, 日期>`，随 P8.0 的方案走档案。任一条勾选显示「建议带宝宝到社区卫生服务中心或儿童保健科做发育评估，以医生为准」。
- 规范另有一条询问项：任何月龄出现语言或社交能力倒退，也算初筛异常。是否一并做，列入 P8.0 待确认，建议做。
- 与 CDC 里程碑并列：CDC 是「可以留意」，这里是「建议评估」，两张卡分开写，避免语气混淆。

### 2.5 喂养与口腔（P8.5）

- 喂养准则只录已核实的条目：0～6 月龄、7～24 月龄各 6 条准则标题，带来源链接，放进对应月龄卡；不写用量，不写维生素 D 剂量。
- 新食物引入：由已有记录的 `food` 字段派生（首次出现的食物名、日期、同条记录的 `reaction`），不新增字段。食物名只做精确匹配，不猜同义词；归并不了的按原文各算一项。观察几天要等 P8.5.0 查到原文，查不到就只显示首次吃的日期。
- 口腔提示：第一颗牙萌出后 6 个月内首次口腔检查、之后每半年一次；多颗牙萌出后每天刷牙 2 次；1 岁后减少奶瓶，1 岁半～2 岁停用。出牙数放在体检记录里填（规范写明 6、8 月龄按实际出牙数填写）；不做萌牙时间表。

### 2.6 入托入学核对（P8.6）

- 输入一个目标日期（家长选入园日期，默认今天），输出到该日期按国家程序应种但未记录的剂次；二选一疫苗未选的标「待选」，乙肝特殊程序沿用已有开关。
- 边界：只知道国家程序，各省增加的疫苗不在内；是否可补种、补种间隔由接种单位判断，应用不给。页面固定文案：仅按国家免疫规划核对，以接种单位出具的评估为准。
- 办法里「开学或转学、插班 30 日内完成查验，需补种的当年 12 月底前复验」只作提示文字，不做倒计时。

### 2.7 就诊摘要补生长（P8.7）

- `buildVisitSummary` 增加最近一次测量与百分位区间文字，复用 `percentileBand`；未填性别时只列数值，不写区间。

## 3. 已确认的产品决策（P8.0，2026-11-11 用户确认）

1. **存储选 A**：体检完成记录与发育观察都放进宝宝档案（`profiles[]` 内，结构同里程碑），同步沿用 `mergeProfiles` 按 key 取并集并带取消标记；不改同步服务端。
2. **预警征象与 CDC 里程碑并列**：两张卡分开，CDC「可以留意」保持原样，不替换。
3. **加入「语言或社交能力倒退」询问项**：任何月龄都可勾选，勾选后与预警征象同一条提示；存在 `warningSigns` 里一个固定 key，不属于某个检查点。
4. **新生儿访视和满月放进日程**：访视（出院后 1 周内）只作清单项、没有参考日期；满月按出生后 28～30 天，不按自然月。

## 3.1 功能细节（2026-11-11 用户确认：全部按默认，需求定稿）

1. 提醒范围：体检节点只在健康页显示状态，今天页不加提示、不做推送（默认）；或 30 天内到期时今天页加一行。
2. 睡眠参考：趋势图画参考带，今日卡片写参考范围，两处都做（默认）。
3. 新食物引入记录入口：放健康页，不另开页面（默认）。
4. 入托入学核对：目标日期默认今天，可打印（默认）。
5. 身长别体重 / 身高别体重（表 A.5–A.8）：本期不做，BMI 上线实测后再定（默认）。
6. AI：P8 新入口（体检、预警征象、入托核对）不接 AI、不做语音录入，与疫苗清单、生长百分位同一口径（默认）。

## 4. 风险与未验证

- 体检规范的版本号与听力方法措辞（行为测听 / 听性行为观察）两个转载版不同，录入前核对原文（P8.1.1）。
- 表 A.9/A.10 的年龄列是「岁 月」写法，提取后要逐行回查 PDF，不能只靠格式校验。
- 部分原文来自地方卫健委或转载站，已多份互核，但以 nhc.gov.cn 原文为准；找不到权威原文的条目不进数据。
- 医疗边界：预警征象与睡眠参考最容易被读成判断。P8.4.4 加文案守门测试，睡眠对照也补一条文案测试。
- 真机待办：.ics 导入、打印存 PDF、体检记录的多设备同步，需要你实测，记入 `docs/VALIDATION.md`。
- 范围：P8 不新增运行时依赖；选方案 A 时不碰服务端；新字段全部可选，原则上不升备份版本号，实现时以旧备份导入测试为准。
