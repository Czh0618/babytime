# BabyTime · 宝宝时光

将已确认设计落地为可运行的移动端 H5，采用 Vue 3、TypeScript、Vite。宽屏显示侧边导航，手机显示底部导航。

## 本地运行

推荐 Node.js 24 及以上版本；此项目在 Node.js 26.7.0 / npm 11.19.0 下验证。

```sh
npm ci
npm run dev
```

访问终端输出的 `http://127.0.0.1:5173`。

```sh
npm test
npm run build
npm run preview
```

## 部署到 ECS

部署脚本从本地构建 `dist/`，通过 SSH 上传到 Ubuntu/Debian ECS，并配置 Nginx。先在项目根目录创建 `.deploy.env`（已被 .gitignore 忽略，不会进入版本库），填写 `DEPLOY_HOST`、`DEPLOY_USER`、`DEPLOY_PUBLIC_IP`、`DEPLOY_DOMAIN`、`DEPLOY_ROOT` 和 `LETSENCRYPT_EMAIL`。

服务器账号需要 SSH 登录权限和 `sudo` 权限，SSH key 登录体验更好。首次 IP 部署前需在安全组入方向放行 TCP 80；端口可通过 `.deploy.env` 中的 `DEPLOY_HTTP_PORT` 修改，默认值为 80。

首次按 IP 部署：

```sh
npm run deploy -- ip
```

备案完成、你的域名 A 记录已指向该服务器且安全组开放 TCP 80/443 后，切换为域名 HTTPS：

```sh
npm run deploy -- domain your-domain.com
```

域名模式会用 Certbot 为根域名申请证书并将 HTTP 跳转到 HTTPS；脚本不会配置 `www` 子域名或修改 DNS。每次部署保留旧版本目录。IP 模式默认通过 `http://<公网IP>/` 提供 HTTP，也可通过 `DEPLOY_HTTP_PORT` 设置其他端口；大陆地域 ECS 仍需先完成 ICP 备案，改端口不替代备案要求。

网页录音需要 HTTPS。备案完成前，可以用 IP 证书提供 HTTPS（安全组需放行 TCP 80/443，`DEPLOY_HTTP_PORT` 保持 80）：

```sh
npm run deploy -- ip-https
```

该模式用 snap 安装 Certbot 5.4+，向 Let's Encrypt 申请 IP 地址证书。证书有效期 6 天，由 `snap.certbot.renew.timer` 自动续期并重载 Nginx；续期失败几天内 HTTPS 就会失效，可在服务器上用 `sudo /snap/bin/certbot certificates` 查看到期时间。续期要求 TCP 80 一直对外可达（Let's Encrypt 从外网验证）；部署后可用 `sudo /snap/bin/certbot renew --dry-run` 走一遍完整续期流程（只用测试环境，不替换正式证书），`systemctl list-timers 'snap.certbot.*'` 查看下次检查时间。服务器若另装有 apt 版 certbot，裸 `sudo certbot` 会命中 /usr/bin 下的旧版，续期检查会误报失败，请一律使用绝对路径。Let's Encrypt 已不再发到期提醒邮件，续期失败不会有人通知。HTTP 继续可用、不自动跳转：浏览器把 `http://` 和 `https://` 当成两个网站，本地数据不共享。改用 HTTPS 前，先在 http 地址的“家庭”页“导出备份 JSON”，再到 https 地址“从备份恢复”；新版备份包含本机可用的原始照片和视频。旧版 JSON 没有原片，恢复后可在对应记录的“编辑记录”中补回，或返回仍保有原片的旧地址重新导出新版备份。

## 当前可用

- 语音重点入口：接入浏览器中文语音识别，实时转写、停止或取消、编辑文字，用本机规则或 AI 整理为多条照护草稿，再确认保存。
- 照护记录：支持喂奶、睡眠、换尿布和备注，保留原话，时间或数量不明确时由家长补充；重复确认同一批次不会重复存档。
- 今天：显示最近的家长照护记录；“还未记录”不代表宝宝没有发生相应事件。
- 月龄参考：按日历月与宝宝生日计算，提供 11 个阶段的关注提示和亲子活动，附 CDC 来源；可手动查看其他阶段，活动可以转成待确认成长记录。
- 时光：按日期浏览、收藏、里程碑筛选、查看和编辑记录；可为成长记录添加、补回或更换照片与视频，保存后生效，取消不修改原片。
- 导入：每批最多 10 个照片或短视频，单文件 100 MB；可读取时长的视频限制为 2 分钟。
- 待整理：真实导入由用户命名、备注和确认；也可让 AI 依据写下的一句话起标题和短文，结果仍是待确认草稿；示例候选明确标记为演示。
- AI 服务：可选接入兼容 OpenAI Chat Completions 的模型服务，配置只存本机；未配置或调用失败时自动回退本机规则，不上传照片和视频。
- 手动记录：无需照片或 AI，也能写下成长瞬间。
- 图文回顾：选择已确认记录、调整顺序、保存、预览、导出离线 HTML。
- 家庭：修改昵称与生日、导出含原片的备份 JSON、兼容恢复旧版 JSON、清除示例、清空数据。
- 删除：可以只删除记录，也可以同时删除原片与关联记录，原片删除与引用更新在同一 IndexedDB 事务内完成。

## 数据与能力边界

照片、视频和结构化记录保存在当前浏览器的 IndexedDB，没有素材上传接口或云同步。不同域名、浏览器与设备之间的数据不互通。清除站点数据会删除本机记录，因此请保留手机相册中的原片。

语音使用 `SpeechRecognition` / `webkitSpeechRecognition`。只有点击“开始说”才启动，浏览器可能把音频交给其语音服务联网处理，开始前会显示说明；BabyTime 不保存原始录音。录音只能在 HTTPS（或 localhost）页面使用：iPhone 的 Safari/Chrome 在 http 页面不提供录音接口，也不弹权限提示，弹窗会提示改用 https 地址。关闭弹窗、页面隐藏、取消或单次到达 60 秒都会停止识别。浏览器不支持、无中文服务、网络失败或麦克风被拒绝时会明确提示；仍可用系统键盘语音填写文字。Safari/Chrome 的具体语言、网络与系统配置会影响可用性。

语音文字整理默认采用本地规则，不联网。支持常见中文时间、奶量、睡眠时长及多事件表达；含糊时刻要求家长确认，计划和否定语句不会当成已经发生的照护行为。若已配置 AI 服务，可改用 AI 拆长句；AI 结果与本机整理走同一套草稿确认流程，时间不明确时同样要求家长确认。保存前务必审阅草稿。

AI 辅助整理是可选功能，默认关闭。在「家庭 → AI 辅助整理 → 设置」填入兼容 OpenAI Chat Completions 的服务地址、模型名称和 API 密钥后，语音弹窗出现「用 AI 整理」，待整理卡片出现「AI 起个名字」。密钥只保存在当前浏览器的 localStorage，不写入工作区或备份 JSON；调用时只发送识别文字或家长写下的一句话，以及素材文件名、类型与拍摄时间，照片和视频原片不会离开本机。模型看不到画面，不会推测画面内容或发育里程碑。浏览器直连第三方服务可能受 CORS 限制；未配置、暂停、网络失败、返回内容不合法时都会给出提示并回退本机整理。模型输出按字段白名单收敛，只写入待确认草稿或 pending 候选，已确认的成长记录不会被重新分析覆盖。调用可能由所填服务方计费。

首次打开为留空工作区。在“时光”页点“先看看示例”可加载示例档案和记录；在“家庭”中清除示例会恢复加载前未填写的宝宝资料，不影响实际导入的素材。示例资料若已由家长保存，则保留保存后的资料。

导入时间默认使用文件修改时间，不承诺等于拍摄时间，可在确认时修改。HEIC、MOV 等格式的预览取决于浏览器编解码支持；无法解码时仍允许保存原片，并显示没有预览的状态。

HTML 回顾包含照片/视频的静态缩略图及文字，不包含原片。新版 JSON 备份包含宝宝资料、结构化记录、录入原话、回顾，以及当前浏览器中可读取的原片与缩略图；恢复时记录和原片在同一事务中提交，损坏文件或存储失败不会覆盖当前记录。本机已缺失的原片无法凭空导出，导出时会明确提示缺失数量，可先在对应记录中补回后重新备份。JSON 内的原片使用 Base64，文件体积和浏览器内存占用会随素材数量增长；大量视频的移动端备份尚需真机验证，请同时保留相册原片。当前不提供 MP4 渲染、照片或视频的画面识别、实时监控或告警。

月龄内容根据 CDC Learn the Signs. Act Early. 的各年龄页改写，核对日期为 2026-11-04；它是陪伴参考，不是个体发育评估。早产宝宝可按儿科医生建议手动选择参考阶段。未填写生日时不会伪造月龄，需先完善资料或手动查看。

## 实现结构

```text
src/
  components/   语音、月龄活动、导入、编辑、详情、原生 dialog、回顾预览
  data/         附 CDC 来源的月龄提示与亲子活动
  views/        时光、待整理、回顾、家庭
  domain/       日期、月龄、语音文字解析、AI 结果收敛、照护记录与回顾规则
  lib/          IndexedDB、媒体预览、持久化操作、AI 服务通道、导出
  styles/       设计变量、组件与响应式布局
tests/          记录幂等、片段边界、引用清理、AI 输出与配置等业务验证
```

后续可替换 `lib/workspace.ts` 的持久化实现来接入业务后台；AI 通道集中在 `lib/ai-service.ts`，换用自建后端时界面与领域逻辑不用改。AI 候选与正式成长记录已经分开，重新分析不会自动覆盖家长的记录。

## 已知限制

- 本机原型没有服务端账号、加密存储或跨设备同步；同一浏览器配置文件的其他使用者也能打开这些记录。
- AI 服务的 API 密钥保存在浏览器本机存储，共用设备时可能被同一配置文件的其他使用者读取，用完可在设置里「清除配置」。设置弹窗里密钥默认明文，方便在手机上切换输入法并用跨设备剪贴板粘贴复杂密钥；点右侧图标可临时隐藏。
- 浏览器直连第三方模型服务受对方 CORS 策略限制；只允许服务端调用的服务需要自建代理。
- 多标签页同时修改尚未处理写入冲突，建议一次只打开一个编辑页面。
- 未在实际 iPhone、Android 设备上完成 HEIC/HEVC、系统存储配额和长时间运行验证。
- TypeScript 固定在 6.0.3；当前 vue-tsc 使用的编译器入口与 TypeScript 7 不兼容。
