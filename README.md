# BabyTime · 宝宝时光

将已确认设计落地为可运行的移动端 H5，采用 Vue 3、TypeScript、Vite。宽屏显示侧边导航，手机显示底部导航。

## 本地运行

推荐 Node.js 24 及以上版本；此项目在 Node.js 26.7.0 / npm 11.19.0 下验证。

```sh
npm ci
npm run dev
```

访问终端输出的 `http://127.0.0.1:5173`。

```sh
npm test
npm run build
npm run preview
```

## 部署到 ECS

部署脚本从本地构建 `dist/`，通过 SSH 上传到 Ubuntu/Debian ECS，并配置 Nginx。先在项目根目录创建 `.deploy.env`填写 `DEPLOY_HOST`、`DEPLOY_USER`、`DEPLOY_PUBLIC_IP`、`DEPLOY_DOMAIN`、`DEPLOY_ROOT` 和 `LETSENCRYPT_EMAIL`。

服务器账号需要 SSH 登录权限和 `sudo` 权限，SSH key 登录体验更好。首次 IP 部署前需在安全组入方向放行 TCP 80；端口可通过 `.deploy.env` 中的 `DEPLOY_HTTP_PORT` 修改，默认值为 80。

首次按 IP 部署：

```sh
npm run deploy -- ip
```

备案完成、你的域名 A 记录已指向该服务器且安全组开放 TCP 80/443 后，切换为域名 HTTPS：

```sh
npm run deploy -- domain your-domain.com
```

域名模式会用 Certbot 为根域名申请证书并将 HTTP 跳转到 HTTPS；脚本不会配置 `www` 子域名或修改 DNS。每次部署保留旧版本目录。IP 模式默认通过 `http://<公网IP>/` 提供 HTTP，也可通过 `DEPLOY_HTTP_PORT` 设置其他端口；大陆地域 ECS 仍需先完成 ICP 备案，改端口不替代备案要求。

网页录音需要 HTTPS。备案完成前，可以用 IP 证书提供 HTTPS（安全组需放行 TCP 80/443，`DEPLOY_HTTP_PORT` 保持 80）：

```sh
npm run deploy -- ip-https
```

ip-https 部署后，80 端口只保留证书自动续期的验证路径，其余 HTTP 请求会 301 跳转到 https；迁移完 http 站的记录后不要再从 http 地址记账（两种来源的浏览器存储互不相通）。Nginx 同时开启 gzip 压缩，并附带 `nosniff`、CSP 等安全响应头。

### 多设备同步（可选）

在 `.deploy.env` 加 `DEPLOY_SYNC=1` 后用 `ip-https` 或 `domain` 模式部署，会在服务器上安装 `babytime-sync`（`server/sync.ts`，只用 Node 标准库，需要服务器 Node.js ≥ 22.18）：systemd 服务只监听 `127.0.0.1:8787`，Nginx 只在 443 上把 `/sync/` 反代过去，数据在 `/var/lib/babytime/sync.db`。首次安装会在终端打印一次家庭密钥（保存在服务器 `/etc/babytime-sync.env`，仅 root 可读），请存进密码管理器，再到每台设备“家庭”页的“多设备同步”里填入。设计、冲突规则与回滚见 `docs/SYNC.md`。

- 关闭同步：家庭页取消“开启同步”或清除密钥，本机与服务器数据都不动。
- 历史照片补传：开启同步后，这台设备上**已经存在**的照片（包括升级到 P7.2 之前导入的）会在下一次同步自动排进上传队列，一张一张补传，不需要重新导入；上次中途失败、或当初解不出预览而没有缩略图的照片，下一轮会单独补传缩略图，家人设备才看得到网格预览。视频始终不上传；单张超过 20 MB 的照片服务器不接收，家庭页会显示这类照片的数量，它们只留在本机。
- 卸载服务：`sudo systemctl disable --now babytime-sync && sudo rm /etc/systemd/system/babytime-sync.service`，去掉 `DEPLOY_SYNC` 后重新部署即可移除 `/sync/` 反代；`/var/lib/babytime/sync.db` 可按需删除。

## 当前可用

- 语音重点入口：接入浏览器中文语音识别，实时转写、停止或取消、编辑文字，用本机规则或 AI 整理为多条照护草稿，再确认保存。
- 一键快记：今天页「记一次」四个按钮（喂奶 / 尿布 / 睡着 / 醒来），默认当前时间，12 秒内可撤销。
- 计时：亲喂（可换边、分侧累计）与睡眠计时，开始时间存本机，页面被杀掉后重新打开仍能继续计时；结束时先生成草稿，确认后才落库。
- 照护记录：支持喂奶、睡眠、换尿布、备注、体温、用药、接种与生长测量，保留原话，时间或数量不明确时由家长补充；重复确认同一批次不会重复存档。
- 今天：显示最近的家长照护记录、今日奶量与睡眠、下次喂奶参考、夜间统计与今日交接摘要；“还未记录”不代表宝宝没有发生相应事件。
- 健康档案：按 2026 年版国家免疫规划推算每剂应种日期与状态（可标记接种、门诊与批号、生成日历文件、添加自费疫苗）；生长曲线画家长自己的测量点，填写性别后叠加 WS/T 423—2022《7 岁以下儿童生长标准》附录 A 的百分位参考线，只描述所处区间、不做发育判断，具体以医生为准；月龄里程碑可勾选并记录达成日期。
- 就诊摘要：最近 7 天照护、体温与用药记录、疫苗状态汇总，支持打印 / 存为 PDF，并可导出带 UTF-8 BOM 的 CSV。
- 月龄参考：按日历月与宝宝生日计算，提供 11 个阶段的关注提示和亲子活动，附 CDC 来源；可手动查看其他阶段，活动可以转成待确认成长记录。
- 时光：按日期浏览、收藏、里程碑筛选、查看和编辑记录；一条记录最多 9 张照片，可加图、删图、左右移动改顺序、逐张补回或换图，第一张作封面；详情页横向滑动看全部照片并可点开大图，列表只显示封面与「+N」角标。含视频时仍是一条记录一个素材。保存后生效，取消不修改原片。
- 导入：每批最多 20 个文件，照片最多 9 张合为一条候选、超出的提示并跳过，视频各自成条；单文件 100 MB，可读取时长的视频限制为 2 分钟。
- 待整理：真实导入由用户命名、备注和确认；也可让 AI 依据写下的一句话起标题和短文，结果仍是待确认草稿；示例候选明确标记为演示。
- AI 服务：可选接入兼容 OpenAI Chat Completions 的模型服务，配置只存本机；语音整理、待整理起名、趋势解读、月度回顾标题、纪念日文案、交接摘要润色与记录问答都可以单独触发；未配置或调用失败时自动回退本机规则，不上传照片和视频。
- 手动记录：无需照片或 AI，也能写下成长瞬间。
- 图文回顾：选择已确认记录、调整顺序、保存、预览、导出离线 HTML。
- 家庭：修改昵称与生日、导出含原片的备份 JSON、兼容恢复旧版 JSON、清除示例、清空数据、可选的多设备同步；双胞胎或二胎可以各自建一份档案，顶部切换，记录、疫苗、生长曲线与里程碑都按宝宝隔离。
- 删除：可以只删除记录，也可以同时删掉这条记录独有的原片（其它记录还在引用的会保留）；原片删除与引用更新在同一 IndexedDB 事务内完成。

## 实现结构

```text
src/
  components/   语音、快记与计时、月龄活动、导入、编辑、详情、趋势与生长图、就诊摘要、AI 卡片
  data/         附 CDC 来源的月龄提示与亲子活动、2026 年版免疫程序静态数据
  views/        时光、健康、待整理、回顾、家庭
  domain/       日期、月龄、语音文字解析、AI 结果收敛与守门、照护记录、睡眠、统计、疫苗、生长、里程碑、纪念日、交接与回顾规则
  lib/          IndexedDB、媒体预览、持久化操作、AI 服务通道、导出、CSV、日历文件
  styles/       设计变量、组件与响应式布局
tests/          记录幂等、片段边界、引用清理、AI 输出与配置、疫苗推算、生长与统计等业务验证
```

后续可替换 `lib/workspace.ts` 的持久化实现来接入业务后台；AI 通道集中在 `lib/ai-service.ts`，换用自建后端时界面与领域逻辑不用改。AI 候选与正式成长记录已经分开，重新分析不会自动覆盖家长的记录。

## 已知限制

- AI 服务的 API 密钥保存在浏览器本机存储，共用设备时可能被同一配置文件的其他使用者读取，用完可在设置里「清除配置」。设置弹窗里密钥默认明文，方便在手机上切换输入法并用跨设备剪贴板粘贴复杂密钥；点右侧图标可临时隐藏。
- 浏览器直连第三方模型服务受对方 CORS 策略限制；只允许服务端调用的服务需要自建代理。
- 多标签页同时修改尚未处理写入冲突，建议一次只打开一个编辑页面。
- 未在实际 iPhone、Android 设备上完成 HEIC/HEVC、系统存储配额和长时间运行验证。
- TypeScript 固定在 6.0.3；当前 vue-tsc 使用的编译器入口与 TypeScript 7 不兼容。
